Groq API 反向代理

Groq 限制中国大陆 IP 访问。本项目部署在 Netlify Functions 上，把 /v1 请求从美国节点转发到 api.groq.com，支持 SSE 流式输出。OpenAI SDK 只需替换 base URL。

部署

仓库包含全部代码，无构建步骤。GitHub 导入或使用 Netlify CLI 即可部署。

01推送到 GitHub

新建仓库并推送本项目，Netlify 选择 “Import an existing project”。

02构建配置

Build command 留空，Publish directory 填 public，Functions directory 填 netlify/functions。这些已写入 netlify.toml。

03或使用 CLI

npm i -g netlify-cli
netlify login
netlify deploy --prod

环境变量（可选）

← 左右滑动查看完整表格 →

变量必填说明
GROQ_UPSTREAM_BASE否上游地址，默认 https://api.groq.com/openai/v1。
RELAY_PASSWORD否设置后请求必须带 x-relay-password 头，防止域名被扫描滥用。
ALLOWED_ORIGINS否跨域来源白名单，逗号分隔，默认 *。
UPSTREAM_TIMEOUT_MS否等待上游响应头的超时，默认 55000（1000–58000）。

修改环境变量后需重新部署（Deploys → Trigger deploy）。

FAQ

Key 安全吗？

Key 只保存在浏览器 localStorage，随请求头 Authorization 经函数透传给 Groq。代理不记录日志、不落库、不做缓存。

注册 Groq 还需要翻墙吗？

需要一次。代理只解决 API 调用阶段的网络可达性，注册与充值仍需能访问 Groq 官网的网络。

为什么不用 redirect 代理？

Netlify 的 redirect 代理会缓冲 SSE 流，且无法处理 CORS、密码与错误格式。Functions 透传响应流，体验与直连一致。

BYOK 反向代理，不存储 API Key 与对话内容。使用请遵守 Groq 服务条款。
